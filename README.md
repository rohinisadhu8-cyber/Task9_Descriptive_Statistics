Task 9: Descriptive Statistics Primer

Objective

To calculate and interpret descriptive statistics using Python and Pandas.

Dataset

Iris Dataset

Tools Used

- Python
- Pandas
- Google Colab

Analysis Performed

- Mean
- Median
- Mode
- Standard Deviation
- 25th, 50th, and 75th Percentiles

Key Findings

Descriptive statistics help identify the central values, variability, and distribution of flower measurements. Comparing mean and median helps identify possible skewness, while standard deviation and percentiles help understand data spread.

Conclusion

This task helped me understand how descriptive statistics summarize numerical data and reveal useful patterns in a dataset.
